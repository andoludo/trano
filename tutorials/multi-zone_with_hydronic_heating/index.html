    Multi-zone with hydronic heating

    The previous tutorials provided idealized examples. In this tutorial, we will simulate a three-zone building with a hydronic heating system, aiming for a more realistic model. Below, we will describe the configuration file, highlighting key points:

    • Default Construction Values: Trano includes a set of predefined construction, glazing, and gas properties. To use these in your configuration file, add the following line: 

      default: !include_default

    • Emission Systems: Each space is assigned a list of emission systems. These are linked to a radiator object (RADIATOR:001) and a valve object (VALVE:001), with the valve being used for control instead of the radiator: 

      emissions:
  - radiator:
      id: RADIATOR:001
  - valve:
      id: VALVE:001
      control:
        emission_control:

    • Hydronic System Definition: A complete hydronic system must be defined, including the boiler, pump, and various valves. Default parameters will be utilized if not specified: 

      systems:
  - boiler:
      id: BOILER:001
      control:
        boiler_control:
  - pump:
      id: PUMP:001
      control:
        collector_control:
      outlets:
        - THREE_WAY_VALVE:001
        - THREE_WAY_VALVE:002
      inlets:
        - BOILER:001
  - split_valve:
      id: SPLIT_VALVE:001
      inlets:
        - VALVE:003
        - VALVE:001
      outlets:
        - BOILER:001
  - three_way_valve:
      id: THREE_WAY_VALVE:001
      control:
        three_way_valve_control:
      outlets:
        - TEMPERATURE_SENSOR:001
        - SPLIT_VALVE:001
  - temperature_sensor:
      id: TEMPERATURE_SENSOR:001
      outlets:
        - RADIATOR:001
        - RADIATOR:003
  - split_valve:
      id: SPLIT_VALVE:002
      inlets:
        - VALVE:002
      outlets:
        - BOILER:001
  - three_way_valve:
      id: THREE_WAY_VALVE:002
      control:
        three_way_valve_control:
      outlets:
        - TEMPERATURE_SENSOR:002
        - SPLIT_VALVE:002
  - temperature_sensor:
      id: TEMPERATURE_SENSOR:002
      inlets:
        - THREE_WAY_VALVE:002
      outlets:
        - RADIATOR:002

    Why the layout of this tutorial is wrong

    The pump of this tutorial is before the three-way valves

    This tutorial wires the hydronic system as boiler -> pump -> three-way valves -> sensors -> radiators. That layout does not work as a supply temperature control, and Trano reports it with a HydronicLayoutWarning ("WRONG HYDRONIC LAYOUT") on each three-way valve. It is kept as it is so that existing models keep working; build new models as in Hydronic heating with mixing circuits.

    What the three-way valves are meant to do. Each valve has a controller that measures the water after the valve (TEMPERATURE_SENSOR) and should hold it at a set point, 90 degC by default, by mixing the hot water of the boiler with the cooler return water of the radiators.

    What they do here. The pump pushes the water into port_1 of the valves. The water inside a valve is then at a higher pressure than the return, so port_3 sends water back to the boiler instead of drawing return water in. Closing the valve diverts hot water to the return; the water that still reaches the radiators is as hot as the boiler supply. The valve can reduce the flow to the radiators, never lower their temperature.

    What goes wrong. The boiler charges its storage tank until the bottom of the tank is 5 K above tsup_nominal, so the top of the tank, which feeds the radiators, ends about 15 K above it: about 95 degC with the default 80 degC. Above the 90 degC set point, the controller closes the valve to cool the water; that does not cool it, so it keeps closing until the valve is shut. Almost no water reaches the radiators, the sensor sits in still hot water and keeps reading "too hot", and the valve never reopens. In simulation, the rooms of tests/models/three_zones_hydronic.yaml averaged 16 degC instead of 21 degC. This tutorial avoids it only because its boiler is set to 70 degC (tsup_nominal: 343.15): the tank stays below 90 degC, the valves stay fully open and in fact control nothing.

    The workaround Trano applies. When the supply of a storage boiler can exceed the set point of such a valve, Trano raises the set point of the valve 5 K above the expected top of the tank (100 degC for the default 80 degC boiler) and says so in the warning ("WORKAROUND APPLIED"). The valve then stays open and the rooms are heated again (21 degC in simulation), but the radiators receive the boiler water unmixed: nothing limits their supply temperature, the radiator valves alone control the rooms. To make it an error instead, filter the warning: warnings.simplefilter("error", HydronicLayoutWarning) (from trano.validation.issues).

    The fix. Put one pump after each three-way valve and its sensor, and list the return split valve in the inlets of the valve: the pump then draws the return water into the valve, which mixes and holds its set point (supply_temperature_setpoint of three_way_valve_control) whatever the boiler supply. See Hydronic heating with mixing circuits.

    The following code snippet demonstrates how to create the model using Trano with the IDEAS library.

    Test tutorials
        from trano.main import create_model

    create_model(
        path_to_yaml_configuration_folder / "three_zones_hydronic_heating.yaml",
        library="IDEAS",
    )

    General Explanation

    The code snippet imports a function to create a model based on a YAML configuration file for a specific hydronic heating system. It uses a library named "IDEAS" for its functionalities.

    Parameters Description

    • path_to_yaml_configuration_folder:

    • Path object pointing to the directory containing YAML configuration files.

    • "three_zones_hydronic_heating.yaml":

    • The specific YAML configuration file that defines the model parameters and settings for a three-zone hydronic heating system.

    • library:

    • A string that specifies the library to be used for model creation. In this case, it is set to "IDEAS".

    Results

    Two January weeks simulated with IDEAS: the zone temperatures against their set point and the outdoor temperature, the heat the radiators give the rooms and the gas the boiler burns as it charges its storage tank in cycles (all on the data bus of the model). The rooms are heated to 21 degC from 7 to 19 h and fall back to 16 degC at night.
