# Reference data

`ashrae140_2020.dat` is the file `Resources/src/ThermalZones/Detailed/Validation/BESTEST/ASHRAE140_data.dat`
of the Modelica Buildings library 13.0.0 (https://github.com/lbl-srg/modelica-buildings, BSD-3 licence
with modifications), unchanged. It transcribes the result tables B8-1 to B8-5 and the hourly data of
ANSI/ASHRAE Standard 140-2020 (Supplemental Files, `RESULTS5-2A.xlsx`) for the reference programs
BSIMAC, CSE, DeST, EnergyPlus, ESP-r and TRNSYS, and the acceptance limits of Addendum b for the
annual heating and cooling loads.
